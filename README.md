# YUBI CAD（ユビキャド）

旧仮称：内装図面メーカー。名前とロゴは 02_ブランディング/商品名.md（商標は弁理士確認前）。

内装改修の現場で、タブレット(ペン)を使い **実測値を入力しながら平面図を作る** ブラウザアプリです。
ビルド不要の HTML/JavaScript のみで動作し、データは端末内(IndexedDB)に自動保存されます。

## 主な機能

| 機能 | 内容 |
|---|---|
| 下図の読み込み | 間取り図の画像を読み込み/撮影。「縮尺合せ」ツールで既知の長さをなぞって実寸を入力(「一緒に拡大縮小」の対象は自動検出の壁・柱と、設備・文字・写真などの位置。寸法を入れて描いた壁は動かさない) |
| 構造体の特定 | 端末内の画像処理で太く塗られた壁・柱を自動検出 / Claude API による解析(構造壁・間仕切壁・柱・キッチン/トイレ/浴室/洗面などの範囲) |
| 壁なぞり → 寸法入力 | ペンで壁をなぞると、その位置に寸法入力ウインドウが開く。既存の壁をなぞると実寸に修正 |
| 分割と建具 | 壁を始点から順に分割し、片開き戸・両開き戸・親子ドア・片引き戸・引違い戸・引込み戸・折れ戸・両折れ戸・一般のガラス窓・はめ殺し窓・小型開閉窓・開口を配置。吊元・開き方向・敷居を指定可 |
| 設備 | システムキッチン・ユニットバス・トイレ・洗面化粧台・洗濯機パン等をプリセット寸法または品番で配置。品番は Claude のウェブ検索で外形寸法を取得(結果は端末にキャッシュ) |
| 図面表記 | 寸法線(分割寸法+全長)、通り芯(縦 1,2,3… / 横 A,B,C…、通り芯間寸法付き)、室名、任意寸法 |
| 用紙 | A4/A3/A2、縮尺自動または 1/10〜1/200。右下の表題欄に会社名・物件名・図面名・図面番号・縮尺・作成日・作成者・許認可番号。スケールバー・方位・備考 |
| 展開図 | 画面上部の「平面図｜展開図」で切り替え。室名を置いた部屋ごとに A面(北)・B面(東)・C面(南)・D面(西)を1枚の用紙に表示。建具・壁付けの設備も表記。印刷/PDF・PNG・SVG |
| 現場写真 | 「写真」ツールで図面をタップ → 撮影/選択。図面に番号付きの記号と撮影方向の扇形を表示。記号から写真を開ける。写真一覧(写真台帳)をA4で印刷 |
| 写真で建具を測る | 壁を選んで「写真で測る」。壁の写真で四隅を合わせ、実測した壁の幅・高さを入れると歪みを補正。補正した画像で建具を囲むと、位置・幅・腰高・高さを計算して壁の分割欄に反映(AI不要) |
| 仕上表・概算見積 | 画面上部の「見積」。部屋ごとの床・壁・天井面積、巾木・廻り縁の長さ、建具・設備の個数を図面から自動計算。材料単価・工賃単価を入れると金額・消費税・合計を自動計算。印刷/PDF、CSV(Excel) |
| 出力 | 印刷/PDF、PNG(約200dpi)、SVG、DXF(JW-CAD・CAD用)、データ(.json)の書き出し・読み込み |

## 起動方法

### パソコンで試す
```sh
cd naiso-zumen
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
`index.html` をダブルクリックで開いても動きますが、オフライン対応(Service Worker)は無効になります。

### タブレットで使う
HTTPS で配信すると、ホーム画面に追加してアプリのように使え、オフラインでも動作します。
例: このフォルダを GitHub Pages / Netlify / Cloudflare Pages などに置く。

## 操作

- **吸着(画面下の「スナップ」)**: 柱・設備を置く/動かすと、辺が近くの壁・柱の面にそろう(柱は壁の芯にも合う)。壁の端は他の壁の端・柱の面・壁の芯(T字)に合う。壁の端は柱の角には吸着しない(壁厚の半分ずれるため)

- **ペン**: 作図 / **指1本**: 画面移動 / **指2本**: 拡大縮小(「指で描く」ON で指でも作図)
- 長さ欄は `1820+910` のような計算式、全角数字も入力可
- 壁の「左/右」は、なぞった方向(始点→終点)に向かって見た側
- 検出結果(オレンジ破線)は未確定。選択して「確定」、またはメニューから一括確定

## ベータ版の配布・フィードバック

本アプリは、リフォーム会社向けの試験運用版として配布できます。以下の方法で、タブレット版とPC版の両方から図面を共有・送信できます。

### 1. 図面の共有

1. メニュー → 「図面一覧・新規作成」で対象図面を開く
2. メニュー → 「データ書き出し(.json)」で図面データを保存する
3. メニュー → 「PNG画像で保存」または「印刷 / PDF保存」で、図面を送付できる形式にする
4. メール、チャット、社内共有サービス、または現場での確認画面で送信する

### 2. 画面を送る場合

- **タブレット**: ホーム画面に追加して起動し、保存済み図面をそのまま確認、PNGやPDFで送信する
- **PC**: ブラウザのタブで開き、PCの画面サイズに合わせて拡大縮小し、印刷プレビューからPDFを保存する
- **両端末**: `.json` とPNGまたはPDFを同時に添付し、図面や寸法チェックの結果を確認できるようにする

### 3. フィードバックの収集

フィードバックは次の項目をまとめて依頼してください。

- 使いやすかった画面・操作
- 困った箇所・判断しづらかった箇所
- 必要な建具・設備・部材、間取の種類
- 操作にかかった時間
- タブレットとPCでの違い
- 図面の見やすさ、印刷/PDF、PNG出力の品質
- 改善提案と優先度
- バグ・エラーの内容と、発生した図面名

### 4. フィードバックの送信テンプレート

```text
件名: 内装図面メーカー β版フィードバック

会社名:
担当者:
使用端末: タブレット / PC
OS・ブラウザ:
対象図面:

1. 使いやすかった点:
2. 困った点:
3. 欲しい機能:
4. 図面の品質・印刷・PDF・PNG:
5. 改善提案:
6. 追加で確認したいケース:
```

> 図面データには現場情報や会社情報が含まれる場合があります。フィードバック先は社内の管理者が指定するメールや共有サービスを利用してください。

## 利用マニュアル

### 1. 図面を作成する

1. メニュー → 「図面一覧・新規作成」を開く
2. 図面名、物件名、作成日、会社名などを入力する
3. 物件の平面図がある場合は「下図画像を読み込む / 撮影」を使う
4. 「縮尺合せ」で基準となる長さをなぞり、実寸を入力する

### 2. 壁と構造体を入力する

1. 「壁なぞり」で壁をなぞる
2. 壁の長さ、壁厚、種別を入力する
3. 始点から順に、ドア・引き戸・折れ戸・窓などを追加する
4. 「構造壁・柱を自動検出」を使うと、下図から壁・柱を仮配置できる
5. 確定できるものは「確定」、不要な検出結果は削除する

### 3. ガラス窓を入れる

- **一般のガラス窓**: 通常の固定ガラス窓を表記する
- **はめ殺し窓**: ガラスを枠に固定した窓を表記する
- **小型開閉窓**: バスルームなどの小窓。吊元と開き方向を指定する
- **引違いサッシ**: 引違い戸として登録し、枚数と敷居を指定する

### 4. 設備・家具・床を追加する

- 「設備」: キッチン、トイレ、浴室、洗面、冷蔵庫など
- 「家具」: テーブル、椅子、ソファ、ベッドなど
- 「床」: フローリング、カーペット、タイル、畳など
- 「室名」: 部屋名や用途を入力する
- 「水回り」: キッチン・トイレ・浴室・洗面の範囲を表示する

### 5. 図面を確認する

- 「チェック」ボタンで寸法や建具の重なりなどを確認する
- 異常箇所の番号を選び、図面上で修正する
- こまめに「元に戻す」を使う
- 必要な場合は「要再測リストを印刷」で現場向けの確認票を作る

### 6. 図面を保存・出力する

- **端末内保存**: 自動保存される
- **データ保存**: メニュー → 「データ書き出し(.json)」
- **図面の共有**: PNG、PDF、SVGを保存する
- **印刷**: プレビューから「印刷 / PDF保存」を選ぶ

### 7. 展開図を見る(平面図と切り替え)

1. 平面図で、部屋の中に「室名」ツールで室名(例: 洋室1)を置く
2. 画面上部の「平面図｜展開図」で「展開図」を押す(メニュー →「展開図を表示」でも同じ)
3. 「部屋」で部屋を選ぶと、その部屋の A面(北)・B面(東)・C面(南)・D面(西)が1枚に並ぶ
4. 展開図の壁や建具をタップすると、平面図に戻ってその壁の編集画面が開く(壁高、建具の高さH・腰高もここで入力)
5. 「印刷 / PDF」「PNG保存」「SVG保存」で出力する

> - 室名の位置から上下左右に壁を探し、部屋の内側から見た図にします。図面の上を北として扱います
> - 対象は水平・垂直の壁だけです(斜めの壁は表示されません)。L字の部屋は、室名から見える範囲の四角形として扱います
> - 天井高(CH)は、その部屋の壁の「壁高」の最大値です(既定 2700mm)
> - 建具の高さは、壁の編集画面の分割欄で「高さH」と、窓・開口は「腰高」(床から下端まで)を入力できます。空欄のときは標準値(ドア H2000、襖・障子 H1800、窓 腰高900・H1100、小窓 腰高1200・H600)で描き、図に「*」を付けます
> - 腰高+高さが壁高を超えると保存できません
> - 設備は、設備の画面で入力した高さ H で描きます
> - 設備・造作家具は、背面がその壁に付いていて、向きが壁の方向と合うものだけを表示します
> - 壁が見つからない方向は「この方向の壁が見つかりません」と表示します

### 7-2. 現場写真を図面に記号で付ける

1. 左の「写真」ツールを選び、写真を撮った位置をタップする
2. 「撮影する / 写真を選ぶ」で撮影するか、撮影済みの写真を選ぶ
3. 番号(自動で連番)、撮影した向き(図面上の上・右上・右…の8方向)、メモを入れて「OK」
4. 図面に、番号入りの丸と撮影方向の扇形が付く。記号をタップ →「写真を見る」で写真を大きく表示。「向き45°」で向きを回せる。記号はドラッグで移動できる
5. メニュー →「写真一覧(写真台帳)を印刷」で、A4縦に3枚ずつ(番号・場所(室名)・向き・メモ付き)印刷/PDF保存できる

> - 写真は長辺1600pxのJPEGに縮小し、端末の中(図面データとは別の保存場所)に保存します。1枚あたり数十〜数百KB
> - 「データ書き出し(.json)」には写真も含まれます。別の端末で読み込むと写真も移ります
> - 図面を削除すると、その図面の写真も削除されます
> - 画面下の「写真」のチェックを外すと、画面上の記号を隠せます(印刷には出ます)

### 7-3. 壁の写真で建具の位置・大きさを測る

1. 平面図で壁を選び、上の「写真で測る」を押す
2. 「壁を撮影する / 写真を選ぶ」で、壁の正面寄りから **四隅(床の左右・天井の左右)がすべて写る** ように撮る
3. ① 四隅を合わせる: ○ を床の左端・床の右端・天井の右端・天井の左端へドラッグ。壁の幅・高さに実測値(内法)を入れ、「写真の左端」が壁の始点側か終点側かを選んで「次へ」
4. ② 建具を囲む: 歪みを補正した壁の画像の上で、ドア・窓を対角にドラッグして囲む。種類・位置・幅・腰高・高さは右の一覧で直せる
5. 「壁に反映」で、その壁の分割欄(建具の位置・幅・高さ・腰高)と壁高が更新され、壁の編集画面が開く。展開図にも反映される

> - 計算の基準は、入力した壁の幅・高さ(実測値)です。写真から読み取った値は目安で、四隅の合わせ方やレンズの歪みにより数cm程度の誤差が出ることがあります
> - 床から150mm未満で始まる四角はドア(腰高0)、それ以外は窓として追加します(種類はあとで変更可)
> - 今の分割(ドア・窓)がある壁では、置き換えてよいか確認します
> - 写真はこの画面の中だけで使い、保存しません(記号として残したい場合は「写真」ツールで追加)

### 7-4. 仕上表・概算見積

1. 平面図で、部屋の中に「室名」を置く(床仕上げは「床」ツールで範囲を囲む)
2. 画面上部の「見積」を押す
3. **仕上表**: 部屋ごとの床仕上げ・床面積・壁面積・天井面積・天井高・巾木・廻り縁が出る
4. **概算見積**: 図面から作った行(床仕上げ別・壁・天井・巾木・廻り縁・建具の種類別・設備の種類別)に、材料単価・工賃単価(円)を入れると、材料費・工賃・金額・小計・消費税・合計を自動計算
   - 数量欄の薄い数字は自動計算。数字を入れると上書き、空欄に戻すと自動に戻る
   - 「除外」にチェックすると見積に含めない
   - 配管・解体・養生・運搬・諸経費などは「＋行を追加」で手入力
   - 消費税率は合計欄で変更できる(既定10%、1円未満切り捨て)
5. 「印刷 / PDF」で概算見積書(A4縦、仕上表付き)、「CSV保存(Excel)」で表計算ソフト用のファイル

> - 計算のしかた
>   - 床・天井面積: 室名の位置から見つけた四方の壁の内法(四角い部屋として計算)。床仕上げは「床」の範囲と部屋が重なる面積
>   - 壁面積: 各面の内法の長さ×壁高 − 建具の開口(幅×高さ。高さ・腰高は分割欄の値、空欄は標準値)
>   - 巾木: 部屋の周長 − 床から始まる建具(ドア・開口)の幅。廻り縁: 部屋の周長
>   - 建具: 壁の分割欄の建具を種類ごとに数える。設備・造作家具: 種類ごとに数える(置き家具は数えない)
> - 単価は空欄から始まります。入力した単価・品番・名称は、この端末の「単価表」に記憶され、次の図面の同じ行に薄い字で入ります(上書き可)
> - 品番からの価格のネット検索(🔍)は製品版の機能です(AI・APIキーが必要。ベータ版では表示しません)。検索結果は材料単価に入るので、必ず確認してください

### 7-5. DXFで保存(JW-CAD・CAD用)

- 平面図: メニュー →「DXFで保存(JW-CAD・CAD用)」。展開図: 展開図の画面の「DXF保存」
- 形式: AutoCAD R12 の DXF、文字コードは Shift_JIS(JW-CADで日本語が文字化けしない)、寸法は実寸 mm
- JW-CADでは「DXF読込」で開き、縮尺を保存時に表示される 1/○○ にすると用紙どおりの大きさになる(図面枠・表題欄も含む)
- 画層(レイヤー): 壁・柱・建具・設備・家具・床・寸法・文字・通り芯・写真・図面枠(展開図は 展開図・図面枠)。線種: 実線、破線(DASHED)、通り芯は一点鎖線(CENTER)
- ドアの開き線は円弧(ARC)、その他は線(LINE)・円(CIRCLE)・文字(TEXT)。壁の塗り・ハッチング・床の模様は出さない(JW-CAD側で必要ならハッチングする)

### 8. ベータ版での確認ポイント

- 壁の長さや内法の入力は、実測値と図面が合っているか確認する
- ガラス窓の種類、尺寸、開き方向、敷居を確認する
- 建具や設備が重ならないか、開き方向が壁や設備にあたらないか確認する
- タブレットの画面サイズとPCの画面サイズで、図面の見え方や操作性を比較する
- 結果をPNGまたはPDF、必要に応じてJSONで添付してフィードバックする

## 版の切り替え(ベータ版 / 製品版)

`js/config.js` の `aiEnabled` で切り替えます。

| 設定 | 動き |
|---|---|
| `aiEnabled: false`(ベータ版・現在) | 「AIで図面を解析」メニュー、設備の「品番の寸法をネット検索」、設定のAPIキー欄を表示しない。AIの呼び出しも止める(外部への送信なし) |
| `aiEnabled: true` | AI機能を使える(下記) |

`label` は画面上部に出す版の表示(例:`β版`)。空欄にすると出ません。
config.js を変えたら、`sw.js` の `CACHE` の番号を1つ上げてください(タブレットに古い版が残らないように)。

## AI 機能について

メニュー →「設定」で Anthropic API キーを入力すると使えます(既定モデル `claude-opus-5-5`)。
キーは端末のブラウザ内にのみ保存され、ブラウザから直接 Anthropic API を呼び出します。
共用端末では入力しないでください。社内で配布する場合は、キーをサーバー側に置く中継 API に切り替えることを推奨します。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/config.js        版の切り替え(ベータ版でAI機能を止める)
js/store.js         設定・保存(localStorage / IndexedDB)
js/catalog.js       壁種別・建具・設備プリセット・用紙
js/render.js        図面描画(壁・建具記号・寸法線・通り芯・図面枠・表題欄)
js/detect.js        下図からの構造壁・柱の簡易検出
js/photomeasure.js  壁の写真で建具を測る(四隅の射影変換で歪み補正)
js/dxf.js           DXF書き出し(画面の図をR12・Shift_JIS・実寸mmに変換)
js/estimate.js      仕上表・概算見積(図面から数量を計算、単価表の記憶、印刷・CSV)
js/elevation.js     展開図(室名から部屋の壁を探し、A〜D面を用紙に配置)。写真台帳の「場所」の判定にも使用
```

## 内法(実測値)入力

- 壁の長さは **内法(壁の面から面)** で入力します(設定で壁芯に変更可)。
- 作図上の壁の長さ = 内法 + 始点側でつながる壁の厚み分 + 終点側でつながる壁の厚み分。
- なぞった時点の位置は仮置きです。端に壁をつなぐ・壁厚を変えると、`js/solve.js` が長さを再計算し、後から描いた壁を平行移動して追従させます。
- 先に描いた壁は動かさないため、一周して実測値の辻褄が合わない分は、最後の壁の端の「ずれ」として寸法チェックに表示されます。
- ドア等の分割位置と寸法線も、始点側の壁の面から数えた内法で表示します。

## 寸法チェック(コーション)

実測値の辻褄が合わない箇所を自動で洗い出し、図面上に ⚠番号 で表示します(印刷には出ません)。

| チェック | 区分 |
|---|---|
| 建具・分割の合計が壁の長さを超える | 要再測 |
| 壁の端が隣の壁とずれている(閉じていない) | 50mm超は要再測 |
| 向かい合う壁の長さが違う | 50mm超は要再測 |
| 設備・造作家具が壁・柱に食い込む(収まらない) | 要再測 |
| 設備どうしが重なる | 要再測 |
| ドア・折れ戸の開閉範囲が壁・設備・家具に当たる | 要再測(置き家具は要確認) |
| 入力値が下図の長さと大きく違う(入力ミスの疑い) | 要確認 |
| 寸法の表示値と線の長さの不一致 | 要確認 |

上部の「チェック」から一覧を開き、「測り直す」で該当箇所を修正、「要再測リストを印刷」で番号付き図面と記入欄付きの一覧を出力できます。許容差(既定10mm)は設定で変更できます。
